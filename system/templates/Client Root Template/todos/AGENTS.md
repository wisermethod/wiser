# Todos

The living list of what is still open for this client. Downstream skills do not load this file; they load `memory/`. A later session reads this list to know what is outstanding, who owns it, and whether it blocks.

The list is `current.md`. Do not start a second list. Onboarding writes it. Later sessions append and close rows. A gap written as prose in a brief or in `memory/` is not a todo; put it here with an owner, or it has no owner.

Status values: `gating` (a phase cannot start), `blocking` (a named deliverable cannot start), `needed` (work proceeds but something stays unlabeled), `done` (with the result and a `YYYY-MM-DD` date).

An owner is a named person or a named role. "the requester" is not an owner.
