# Work

Deliverables and their drafts being made for this client. A file and its drafts sit together in a subject folder, never loose here.

This folder is not the waiting room (`inbox/`), not the originals (`sources/`), and not the open-action list (`todos/current.md`).

## Standing subjects

| Folder | Holds |
|--------|-------|
| `onboarding/` | Records from creating this root. See `onboarding/AGENTS.md`. The living todo list is `todos/current.md`, not a file in this folder. |

## Adding a subject

Create a folder named for the body of work. Use a canonical name when one applies: `briefs`, `media`, `content`, `research`, `campaigns`, `crisis`, `assets`. Do not create the folder until the first file needs it.

A body of work that fits none of those names gets a folder named for that work, never for this client, and never with a comparative in the name.

## Plays and Playbooks

They live in the subject folder they serve, not in top-level `plays/` or `playbooks/`. Do not create those directories.

| Kind | Filename | Example |
|------|----------|---------|
| Recipe, one sitting, different inputs | `<does-this-thing>.play.md` | `work/content/monthly-byline.play.md` |
| Living plan for this run | `<does-this-thing>.playbook.md` | `work/campaigns/Q4-2026/q4-launch.playbook.md` |
| Reusable plan, Type Template | `<does-this-thing>.playbook.md` in the parent of the runs | `work/campaigns/launch.playbook.md`, copied into each campaign folder |

No date in the living filename. The subject folder is the run. A completed run's playbook is archived next to itself per `standards/conventions.md`, and that archive name carries the date.

The deliverable the Play or Playbook produces sits in the same subject folder. The instruction file is not the deliverable.

## When a subject folder gets AGENTS.md

When it holds folders of its own, or has outgrown a quick scan. That file names what the folder holds and where its parts sit. The constitution's chain reaches it with no further declaration.

## Two-hop test

A file here is findable in two hops: this table or a canonical or added subject name, then the file, or the subject folder's own AGENTS.md. A file that cannot be found that way is misfiled.
