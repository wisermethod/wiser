# Programs

Standing concerns with no completion condition live at `programs/<slug>/`, and a program may hold programs of its own, at any depth, as well as projects. A project lives inside the program it serves, or at `work/<slug>/` without one. Each states its own completion condition or standing concern in its `AGENTS.md`. This router projects `standards/user-root.md` C4; read C4 before filing or classifying a folder here. Do not create slug folders before a concern is named.
