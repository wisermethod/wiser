# Programs

Standing concerns with no completion condition live at `programs/<slug>/`. A program may hold programs of its own, at any depth, as well as projects. A project with a written completion condition lives inside the program it serves, or at `work/<slug>/` without one. Each states its own completion condition or standing concern in its `AGENTS.md`. Unsure is a project. This router projects `standards/user-root.md` C4. Do not create slug folders before a concern is named.
