# Glossary

The words this plugin uses with a fixed meaning, each defined once here and used the same way everywhere. Where a file defines a term in full, it is named.

- **Wiser** is this plugin. **WISER** is the method behind a Playbook (`standards/playbook.md`); its five canons are Witness, Interrogate, Solve, Expand, Refine.
- **The constitution** is `AGENTS.md` at this root. **The chain** is the sequence of `AGENTS.md` files a session loads: this one first, then the working folder's.
- **Working folder** is the folder you attach for the work: yours, your organization's, a client's, a department's, or an industry's. **User root** is the same folder seen as one of those five types, a folder carrying that declaration; `skills/Onboard Root/` creates one from a template in `system/templates/`. **Owning root** is the attached root that owns the output of this session; with one folder attached, it is the working folder, and with several, the constitution's Workspace Model says which one.
- **Primitive** is a skill, an expert, or a tool (`standards/primitives.md`). A **skill** produces something you ask for by name; an **expert** judges work through a perspective; a **tool** is a script that runs the same way every time. A **connector**, authenticated access to an outside platform, is a fourth kind this release does not ship.
- **Memory** has three uses, and the context says which: the `memory:` line in a primitive's frontmatter lists the **abstract keys** it needs; the **Provides block** in a working folder's `AGENTS.md` binds each key to a file; and `memory/` is the directory in a user root where those files live. A key is **unscoped** when it resolves in the owning root and **scoped**, written `voice:org`, when it resolves in a root of that type.
- **Gap** is a capability this root does not provide that a primitive names as missing, declared in its `gaps:` frontmatter and collected in `system/GAPS.md`. An **honest stop** is what a primitive does when a step depends on a gap, an absent reading, or a tool that could not run: it says which step cannot run and what it would have produced, and produces nothing in its place; a run that stopped this way has done its work (the constitution's Behavioral Core).
- **Consent** is the question this plugin asks once per copy before any tool installs anything: it reports what it would fetch and stops, and the answer is `--install` on that run, or `WISER_ALLOW_INSTALL=1` for an unattended run. The answer is stored as `.wiser-consent` at the plugin root (`tools/RUNNING.md`).
- **Register** has two senses. The **sourcing register** of a claim is where it came from, public, firsthand, secondhand, or inference (`standards/conventions.md`). The **voice register** of a speaker is how formal or close their prose is, one of the things `voice.md` records. **Evidence labels** are the separate marks for how much checking a claim has had, also in `standards/conventions.md`.
- **Work directory** and **subject folder** are where output lands in the working folder: the directory that folder's `AGENTS.md` declares, and a folder inside it named for the subject (`standards/conventions.md`).
- **The Point-At Test** is Ghost Writer's test that every claim names something a reader could point at (`experts/Ghost Writer/EXPERT.md`). **Cognitive Layering** is Content Author's rule that a piece builds each idea before the next needs it (`skills/Content Author/SKILL.md`).
- **A type file** is the file inside a writing skill that carries the rules for one kind of piece, such as `skills/Content Author/linkedin.md` for a post.
- **Play** and **Playbook** are the two shapes for work that spans sessions: a Play is a repeatable procedure (`standards/play.md`), a Playbook is one project's plan with its decisions and learnings (`standards/playbook.md`).
