# Brief boundaries

Apply at Brief step 6 before sending a bounded run, whether or not the brief or preamble already forbids an action.

- Will the builder run a skill or tool? Yes: read the tools' write inventory and network lines, including every tool a skill chain renders through; include their install locations and documented home-directory state in `<targets>`, and name their permitted network reach, and permit required installs before the varied-input run. A browser profile alone does not cover session tokens. Require a case to show the named tool actually ran. No: no skill-chain inventory is needed.
- Does the runner isolate a suite's home? Yes: name everything each suite may still read from the real home and how it reaches it, including each required environment variable, and have the runner set those variables. No: leave its home unchanged.
- Does the brief ban a string from shipped text? Yes: name the exact lines the sweep spares. No: add no sweep exception.
- Does it say to stop and report an uncovered case? Yes: also require finishing every item that does not depend on that case, per the constitution's Behavioral Core. No: add no stop instruction.
