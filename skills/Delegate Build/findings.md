# Verify a finding

Apply at Review step 7 before briefing a fix.

- Does the finding or proposed fix rest on code behaviour? Yes: run that code on the finding's own input and run the proposed fix on the real data it will meet before briefing it. A third-party tool's behaviour is tested by running that tool, not by reading its source alone. No: the cited-file read decides.
- Does the disposition state a cost? Yes: read that cost's own record before writing the line, and state only what it supports. No: add no cost claim.
- Do the file read and any required run support the finding and fix? Yes: carry it to Review step 8. No: do not apply it; state why, with any measurement that refuted it. A required read or run cannot be made: leave it unchecked and do not brief the fix.
