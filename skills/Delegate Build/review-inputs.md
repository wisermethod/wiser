# Review material

Apply at Review step 1 before briefing the review.

- Does the work include a code diff? Yes: attach the tests it touches, or name where they live. No: add no test attachment.
- Did the builder edit existing prose in an instruction, tool or standard file? Yes: have the review list from the diff each existing sentence removed, moved or changed that no brief item replaced, by quoting it or naming its span and giving the text that replaces it, and judge each for a change of meaning or of place. No: add no unasked-sentence list.
- Will text ship? Yes: before review, search the diff for the organisation names and evidence-file names the source records hold, bare filenames included, and remove those traces. No: no shipping-text sweep is needed.
