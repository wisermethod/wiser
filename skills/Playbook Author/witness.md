# Witness checks

- Does the plan rest on model weights? Yes: read their own licence declaration, card or bundle text before planning on them; the downloading package's licence does not cover the weights. No: go on.
- Does source appear to impose a limit? Yes: trace its call sites and read the neighbouring module for the same feature before stating it. No: go on. Is a non-package capability said to be absent? Yes: search for it before stating its absence. No: go on.
- Is a downstream user's reported fix being proposed as a rule? Yes: keep it a hypothesis until measured on more than that user's pages; plan only what the measurements support. No: go on.
- Does the plan use an address a person named? Yes: check its domain against the account's zone list before it enters the plan. Listed: record that. Not listed: ask before treating it as theirs. No: go on.
- Is another session editing a cited source? Yes: cite the commit read and re-read the source when the build starts. No: cite the source normally.
