# Create checks

## Scope

- Did the owner's restatement omit a planned part? Yes: ask whether they meant to drop it before planning on. No: continue.

## Risks

- Is the route's reach being judged? Yes: state where the delivered thing applies first. Does it reach everywhere it applies? Yes: no reach gap. No: record the unmet reach as a risk. No reach judgment: go on.
- Does a word budget precede review? Yes: leave headroom for two rounds or name its raise in advance; past it, raise and log why rather than cut a rule. No: go on.

## Proposals

- Will a proposal bill a connector? Yes: read `list_connections` and the grant's `connect_status` for each gateway it uses before proposing it; state where connected, whether it has ever billed, and what a member without it gets. No: go on.
- Will the plugin carry an asset? Yes: state its bytes and share of the plugin beside the on-demand alternative. No: go on.

## Milestones

- Does more than one task use an inventory? Yes: name it once and have every other task cite it. No: name it in its task.
