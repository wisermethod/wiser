# Answers and evidence

Every question this skill asks and every pick the person makes is numbered and saved, as it happens, to one dated file per run, `memory/answers/YYYY-MM-DD design answers.md`, in the form `standards/user-root.md` C14 declares. It holds a row for each numbered question and pick, and for the person's own words under the numbers `questions.md` gives them, and nothing else: what the run read and every other observation of the run are not rows, and go where this skill names them. `design.md` states the results as usable rules, including the chosen sentence and core words themselves, colour values, typefaces and picks, each citing its answer number in place and naming the dated record so it resolves. It never reproduces an answers-file row: the question, what was shown or its status. Stating the chosen result is not copying that row. Is a file of that name already there from another run today? Yes: write the next free name C14 gives, `YYYY-MM-DD V2 design answers.md` and so on, never overwriting another run. Is the root's layout stamp below the row that declares `memory/answers/`? Yes: before saving, offer the named ask **update root**, as C14 says; do not create `memory/answers/` here or apply the update. Applied: save as above. Declined or not applied: write no answers file and go on with the run; the bound files it writes stand, each result in `design.md` citing the person's words in place as `(Firsthand: <their name>)` rather than an answer number, and `<requester_words>` taken from the conversation. The "not now" outcome in `SKILL.md` Path makes no record and returns the answer without writing.

Each round of boards, each pick within it and the lock itself are numbered answers of their own. Keep the person's ask, free comments and changes as numbered answers too, preserving every word and its order for `<requester_words>`.

For the sitting, use the question numbers in `questions.md` Answer numbers, and Ask in a Form's C14 rows, including what was shown, status and the chosen action. Save the bank version from `SKILL.md`. Read only the needed bank section before asking. Observations, source limits and board file paths live with the work, never as invented answers. A returning sitting continues the same saved answers and boards; it does not replay answered screens.
