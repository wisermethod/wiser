# Chatterbox third-party notices

This repository redistributes no packages or model weights. `requirements.lock` pins the complete installed resolution read on 2026-10-27 from the existing CPython 3.11 macOS arm64 environment; its `pip check` passes. `packages.json` records each distribution's version, declared terms and requirements as found in installed METADATA; where METADATA carries a licence's full text, it records that licence's name and the project's source address instead, and the full text stays in the installed METADATA. A clean install of this lock has not been exercised. pip installs without `--require-hashes`; the tool checks installed files against every locked distribution's RECORD, fully hashing on installation and before synthesis/trial. RECORD itself and generated bytecode may omit hashes/sizes; all supplied hashes/sizes are checked, and other unhashed entries are refused. RECORD checks are integrity checks, not independent wheel authentication.

## Model artifacts and watermark

The local engine uses `ResembleAI/chatterbox` at revision `5bb1f6ee58e50c3b8d408bc82a6d3740c2db6e18`. `weights.json` records the exact five files, their byte sizes and SHA-256 digests from the existing local Hub snapshot. The [Hugging Face model card for `ResembleAI/chatterbox`](https://huggingface.co/ResembleAI/chatterbox), read 2026-10-27 as supplied by the operator, declares `License: mit` for the model weights and states that every output carries Resemble's Perth watermark. These model-card terms accompany the two packages' MIT terms above.

`perth-files.json` independently pins the size and SHA-256 of `resemble-perth` 1.0.1's bundled `perth_net_250000.pth.tar` (37,429,684 bytes) and `hparams.yaml` (257 bytes). Those pins were taken from that version's installed RECORD and cross-checked against both payloads on 2026-10-27. Mismatches and additional checkpoints are refused before any model loads.

Every generated output carries Resemble's Perth watermark: the pinned `chatterbox/tts.py` constructs `PerthImplicitWatermarker` at line 126 and applies it to generated audio at line 271, with no switch on this path. The speech model runs on Apple's GPU and the package's watermark network on the CPU. Moving PerthNet to MPS was tried in a real take on 2026-10-27; torch 2.6.0 refused its `aten::angle` operation there, so the CPU default remains. Trimming and joining follow generation; watermark detectability after those operations has not been independently tested.
